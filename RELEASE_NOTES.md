# nmap-flow-analyzer v1.6.0

This coordinated stable release adds the Shadow Core ingestion contract and
Shadow Evidence integration while preserving human-reviewed firewall-policy
boundaries. It includes offline Python and standalone Linux packaging.

Ubuntu 26.04 packages must pass their current-source build and artifact smoke
gates before assembly. Rocky Linux, Windows, and GUI completion remain outside
this Ubuntu release-candidate milestone.

The software recommends firewall candidates for human review; it does not
implement security policy changes.
